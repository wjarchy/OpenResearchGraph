# Contributing

Thanks for helping improve OpenResearchGraph.

1. Open an issue describing the behavior or design change.
2. Keep pull requests focused and add tests for observable behavior.
3. Run `ruff check .`, `pytest`, and `python scripts/check_public_release.py`.
4. Do not submit credentials, private datasets, customer names, copyrighted reports, or generated build artifacts.

By contributing, you agree that your contribution is licensed under the MIT License.
